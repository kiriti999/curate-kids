# Data Model: Video Content Management

**Feature**: Sanity to PayloadCMS Migration  
**Branch**: `001-sanity-payload-migration`  
**Date**: January 18, 2026

## Overview

This data model defines the structure for video content metadata stored in PayloadCMS with MongoDB Atlas backend. The model supports both URL-based video submissions (YouTube, Facebook, Instagram, LinkedIn) and direct Telegram video uploads with Cloudinary storage.

## Core Entities

### Video

Represents a curated video for children with metadata for categorization, age-appropriateness, and distribution.

#### Fields

| Field | Type | Required | Description | Validation Rules |
|-------|------|----------|-------------|------------------|
| `id` | String (MongoDB ObjectId) | Auto | Unique identifier | Auto-generated by MongoDB |
| `title` | String | Yes | Human-readable video title | Max 500 chars, non-empty |
| `slug` | String | Yes | URL-friendly identifier | Unique, lowercase, alphanumeric + hyphens, max 96 chars |
| `youtubeUrl` | String | Conditional | Full YouTube URL | Required if source='url', valid URL format |
| `youtubeId` | String | Conditional | YouTube video identifier | Required if source='url', alphanumeric, 11 chars |
| `cloudinaryUrl` | String | Conditional | Cloudinary hosted video URL | Required if source='telegram', valid HTTPS URL |
| `cloudinaryId` | String | Conditional | Cloudinary public ID | Required if source='telegram', includes folder path |
| `thumbnailUrl` | String | Optional | Video thumbnail image URL | Valid URL, HTTPS preferred |
| `duration` | Number | Optional | Video length in seconds | Integer, 0-86400 (24 hours max) |
| `category` | String (Enum) | Yes | Content category | Must be one of Category values (see below) |
| `ageRange` | String (Enum) | Yes | Target age group | Must be one of AgeRange values (see below) |
| `tags` | Array<String> | Optional | Descriptive keywords | Max 20 tags, each max 50 chars |
| `source` | String (Enum) | Yes | Video origin type | Either "url" or "telegram" |
| `createdAt` | DateTime | Auto | Submission timestamp | ISO 8601 format, auto-generated |
| `updatedAt` | DateTime | Auto | Last modification timestamp | ISO 8601 format, auto-updated |

#### Relationships

- **One-to-One with Age Range**: Each video targets exactly one age range
- **One-to-One with Category**: Each video belongs to exactly one category
- **One-to-Many with Telegram Groups**: Each video can be distributed to multiple age-appropriate Telegram channels

#### State Transitions

Videos have a simple lifecycle:
1. **Created**: Video submitted and metadata stored
2. **Distributed**: Video sent to age-appropriate Telegram groups
3. *No deletion state*: Videos are retained permanently for historical records

#### Validation Rules

**Cross-Field Validation**:
- If `source = "url"`: `youtubeUrl` and `youtubeId` are REQUIRED, Cloudinary fields must be empty
- If `source = "telegram"`: `cloudinaryUrl` and `cloudinaryId` are REQUIRED, YouTube fields must be empty
- `slug` must be unique across all videos
- At least one of (youtubeUrl, cloudinaryUrl) must be present

**Business Rules**:
- YouTube videos must be embeddable (checked via YouTube API before submission)
- Cloudinary videos are automatically generated thumbnails
- Duration is optional but recommended for better user experience

## Supporting Enumerations

### Category

Represents content subject matter classification.

**Values**:
- `education` - Educational content (learning, tutorials, explanations)
- `entertainment` - Entertainment content (fun, comedy, general enjoyment)
- `music` - Music videos, songs, musical performances
- `science` - Science topics (experiments, discoveries, STEM)
- `arts-crafts` - Arts and crafts activities, creative projects
- `sports` - Sports activities, games, physical activities
- `nature` - Nature, animals, environment, wildlife
- `stories` - Storytelling, narrative content, animated stories

**Validation**: Enum enforced at database level, must match exactly (case-sensitive)

**Usage**: Used for content filtering and organization in admin interfaces

---

### AgeRange

Represents target audience age groups aligned with child development stages.

**Values**:
- `0-2` - Infants and toddlers (0-2 years)
- `3-5` - Preschool age (3-5 years)
- `6-8` - Early elementary (6-8 years)
- `9-12` - Late elementary/middle school (9-12 years)
- `13+` - Teenagers (13+ years)

**Validation**: Enum enforced at database level, exact string match required

**Usage**: 
- Determines which Telegram group receives the video
- Maps to environment variables: `TELEGRAM_GROUP`

---

### Source

Represents the origin type of the video content.

**Values**:
- `url` - Video hosted on external platform (YouTube, Facebook, Instagram, LinkedIn)
- `telegram` - Video uploaded directly via Telegram, stored in Cloudinary

**Validation**: Enum enforced, determines which fields are required

**Usage**: Determines data validation rules and display behavior in bot responses

## Migration Mapping

Mapping from Sanity schema to PayloadCMS schema:

| Sanity Field | PayloadCMS Field | Transformation |
|--------------|------------------|----------------|
| `_id` | *(not migrated)* | MongoDB generates new ObjectId |
| `_createdAt` | `createdAt` | Convert Sanity timestamp to ISO 8601 DateTime |
| `title` | `title` | Direct copy, validate max length |
| `slug.current` | `slug` | Extract from slug object, ensure uniqueness |
| `youtubeUrl` | `youtubeUrl` | Direct copy if present |
| `youtubeId` | `youtubeId` | Direct copy if present |
| `cloudinaryUrl` | `cloudinaryUrl` | Direct copy if present |
| `cloudinaryId` | `cloudinaryId` | Direct copy if present |
| `thumbnailUrl` | `thumbnailUrl` | Direct copy if present |
| `duration` | `duration` | Direct copy if present |
| `category` | `category` | Direct copy, validate against enum |
| `ageRange` | `ageRange` | Direct copy, validate against enum |
| `tags` | `tags` | Direct copy array |
| `source` | `source` | Direct copy, validate against enum |

**Transformation Notes**:
- Sanity uses `slug.current` for slug values; extract the string
- Validate all enum values match allowed values (handle case differences)
- Preserve original creation timestamp from Sanity
- Handle missing optional fields gracefully

## Indexes

Recommended MongoDB indexes for query performance:

```javascript
{
  // Primary key (auto-created by MongoDB)
  "_id": 1,
  
  // Unique slug for video URLs
  "slug": { unique: true },
  
  // Queries by category and age range
  "category": 1,
  "ageRange": 1,
  
  // Compound index for category + age filtering
  "category_ageRange": { "category": 1, "ageRange": 1 },
  
  // Text search on title and tags
  "title_tags_text": {
    "title": "text",
    "tags": "text"
  },
  
  // Sort by creation date
  "createdAt": -1
}
```

**Rationale**:
- `slug` unique index prevents duplicate video entries
- Category/age range indexes support admin filtering queries
- Text index enables search functionality in admin UI
- `createdAt` index supports "recent videos" queries

## Data Integrity Rules

### At Creation
1. Validate `source` determines required fields (youtubeUrl/Id OR cloudinaryUrl/Id)
2. Ensure `slug` is unique before insertion
3. Validate `category` and `ageRange` against allowed enums
4. Auto-generate `createdAt` and `updatedAt` timestamps

### At Migration
1. Count source records in Sanity matches destination records in PayloadCMS
2. Spot-check 10 random records for field-by-field match
3. Verify all required fields are populated
4. Check for duplicate slugs (handle by appending counter if needed)
5. Validate all enum values are valid

### Ongoing Maintenance
1. Prevent `slug` changes after creation (breaks video URLs)
2. Allow `updatedAt` to auto-update on any field change
3. Preserve `createdAt` as immutable historical record

## Storage Estimates

**Average Video Document Size**: ~2KB (2,048 bytes)

**Breakdown**:
- Metadata fields: ~1.5KB (strings, enums)
- MongoDB overhead: ~0.5KB (indexes, internal structure)

**MongoDB Atlas M0 Capacity**:
- Storage limit: 512MB
- Estimated capacity: ~250,000 video records
- Realistic capacity (with indexes): ~200,000 videos

**Growth Projection**:
If submitting 10 videos/day:
- 1 year: ~3,650 videos (~7MB)
- 5 years: ~18,250 videos (~35MB)
- Current free tier sufficient for 50+ years at this rate
