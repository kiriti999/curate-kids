# CuratedReels - Support Tiers & Pricing

## Overview

CuratedReels offers flexible pricing tiers to match your needs, from one-time setup to fully managed hosting.

---

## 💼 Tier 1: One-Time Setup

### Price: ₹15,000 - ₹30,000 ($200 - $400)

**What's Included:**

✅ Complete infrastructure setup:
- MongoDB database configuration
- Vercel frontend deployment
- Deno Deploy bot hosting
- Domain configuration (if provided)

✅ Bot deployment:
- Telegram bot setup
- Age-based group configuration
- Video curation workflow

✅ Admin account:
- Initial admin user created
- Temporary password provided
- Basic usage training

✅ 30-day basic support:
- Bug fixes for setup issues
- Email support
- One configuration change

**Limitations:**
- ❌ No new feature development
- ❌ No SLA guarantee
- ❌ No infrastructure monitoring
- ❌ No updates after 30 days

**Best For:**
- Small organizations testing the platform
- Tech-savvy teams who can self-manage
- Proof of concept deployments
